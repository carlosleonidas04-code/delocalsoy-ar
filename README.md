## Stack

- Monorepo: Turborepo + pnpm
- Base de datos: PostgreSQL + PostGIS (exclusiva, vía docker-compose)
- Transporte: Redis Streams (stream `events:raw`, ADR-032) — `events_raw` sigue siendo la única verdad
- API: Express + TypeScript ESM · CI: GitHub Actions con PostGIS + Redis reales (build + test + flujo vertical en cada PR)

## Primeros pasos

```bash
pnpm install
docker compose up -d          # PostGIS + Redis
pnpm --filter @delocalsoy/db run generate
pnpm --filter @delocalsoy/db run deploy   # migraciones no interactivas
pnpm --filter @delocalsoy/db run seed     # vocabulario idempotente
pnpm --filter @delocalsoy/api run dev
# demo con datos 100% reales:
VITE_DATA_SOURCE=api pnpm --filter @delocalsoy/web run dev   # → /demo
```

Variables de entorno (nombres, nunca valores en el repo): `DATABASE_URL`, `TERRITORIOS_API_KEY`, `HEALTH_MODE_API_KEY`, `REDIS_URL` (transporte ADR-032), `JWT_SECRET` (>= 16 chars — identidad fail-closed sin ella), `BRANCH_PROTECTION` (honesto: `false` — sin regla de rama). Identidad (opcionales, R5a): `RATE_LIMIT_MAX` (default 5) y `RATE_LIMIT_WINDOW_SEG` (default 300) — 429 con `Retry-After` en `/api/auth/{register,login}` (#101). Worker (opcionales): `WORKER_INTERVAL_MS` (default 5000) y `WORKER_STOP_AFTER_PASSES` (0 = infinito). API reportes (opcional, CORE-005 R5): `REPORTES_DUPLICADOS_RADIO_M` (default 100) — radio en metros de la sugerencia de duplicados por proximidad (ADR-039). Reconciliador AUD-08 (#103): `RECONCILE_INTERVAL_MS` (default 60000) y `RECONCILE_WINDOW_MS` (default 86400000).
